`@risuko/risuko-js` provides native Node.js bindings to the Risuko download engine via [napi-rs](https://napi.rs). It ships as pre-built platform-specific binaries — no Rust toolchain needed.

## Installation

```package-install
npm install @risuko/risuko-js
```

Requires Node.js 22 or later. Pre-built binaries cover macOS, Linux (glibc), and Windows on x64 and arm64.

The package is CommonJS, so ESM code imports the default export and destructures the functions from it; named imports such as `import { startEngine } from "@risuko/risuko-js"` fail with a `SyntaxError`.

## Overview

The API is organized into six areas:

| Area | Functions |
|------|-----------|
| [Engine Lifecycle](/docs/node-api/engine) | `startEngine`, `stopEngine` |
| [Task Operations](/docs/node-api/tasks) | `addUri`, `addTorrent`, `addMagnet`, `addEd2k`, `addM3u8`, `addFtp`, `pause`, `unpause`, `remove`, `pauseAll`, `unpauseAll`, `updateTask` |
| [Queries](/docs/node-api/tasks#queries) | `tellStatus`, `tellActive`, `tellWaiting`, `tellStopped`, `getGlobalStat`, `getFiles`, `getPeers`, `getUris` |
| [Events](/docs/node-api/events) | `onEvent` |
| [Options](/docs/node-api/options) | `getOption`, `getGlobalOption`, `changeOption`, `changeGlobalOption` |
| [Session](/docs/node-api/engine#session-management) | `saveSession`, `purgeDownloadResult`, `removeDownloadResult` |

Some engine features have no Node binding and are only reachable over [JSON-RPC](/docs/architecture/rpc) (start the engine with `enableRpc`): `addMedia`, `addMetalink`, `addNzb`, `changePosition`, `getServers`, `forcePause`/`forcePauseAll`, `forceRemove`, the routing-rule methods, and `setBtPeerBlocklist`.

## Quick Example

```js
import risuko from "@risuko/risuko-js";

const { startEngine, addUri, tellStatus, onEvent, stopEngine } = risuko;

await startEngine({ rpcPort: 16800 });

await onEvent((event, gid) => {
  console.log(`[${event}] ${gid}`);
});

const gid = await addUri(
  ["https://example.com/file.zip"],
  { split: "16", dir: "/downloads" }
);

const status = await tellStatus(gid);
console.log(`Progress: ${status.completedLength}/${status.totalLength}`);

await stopEngine();
```

## TypeScript Support

Full TypeScript declarations are included. All types are exported from the main module (type-only imports are erased, so they are unaffected by the CommonJS limitation):

```ts
import type { EngineConfig, EngineEventName } from "@risuko/risuko-js";
```
