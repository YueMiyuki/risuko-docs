Risuko distributes platform-specific binaries via npm. No Rust toolchain or native compilation is needed at install time.

## CLI

Install the `@risuko/cli` package globally:

```package-install
npm install -g @risuko/cli
```

or, use Homebrew (macOS and Linux)
```bash
# CLI
brew install yuemiyuki/risuko/risuko-cli
```

This installs the `risuko` binary. Verify it works:

```bash
risuko --version
```

On Debian, Ubuntu and Fedora you can also install the `risuko-cli` package from the [APT and DNF repositories](#linux-apt-and-dnf). There the command is `risuko-cli`, because `risuko` belongs to the desktop app.

### Supported Platforms

| Platform | Architecture | Package |
|----------|-------------|---------|
| macOS | Apple Silicon (arm64) | `@risuko/cli-darwin-arm64` |
| macOS | Intel (x64) | `@risuko/cli-darwin-x64` |
| Linux | x64 | `@risuko/cli-linux-x64-gnu` |
| Linux | arm64 | `@risuko/cli-linux-arm64-gnu` |
| Windows | x64 | `@risuko/cli-win32-x64-msvc` |
| Windows | arm64 | `@risuko/cli-win32-arm64-msvc` |

The correct platform package is automatically selected via `optionalDependencies`.

### Standalone Binaries

Pre-built binaries are also available on the [download page](/download) and [GitHub Releases](https://github.com/YueMiyuki/risuko/releases). Download the archive for your platform and add it to your `PATH`:

- `risuko-cli-darwin-arm64.tar.gz`, `risuko-cli-darwin-x64.tar.gz`
- `risuko-cli-linux-x64.tar.gz`, `risuko-cli-linux-arm64.tar.gz`
- `risuko-cli-win32-x64.zip`

Windows arm64 is available via npm only.

## Node.js API

Install the `@risuko/risuko-js` package:

```package-install
npm install @risuko/risuko-js
```

This provides native Node.js bindings with full TypeScript definitions.

### Supported Platforms

| Platform | Architecture | Package |
|----------|-------------|---------|
| macOS | Apple Silicon (arm64) | `@risuko/js-darwin-arm64` |
| macOS | Intel (x64) | `@risuko/js-darwin-x64` |
| Linux | x64 | `@risuko/js-linux-x64-gnu` |
| Linux | arm64 | `@risuko/js-linux-arm64-gnu` |
| Windows | x64 | `@risuko/js-win32-x64-msvc` |
| Windows | arm64 | `@risuko/js-win32-arm64-msvc` |

### Requirements

- Node.js 22 or later
- One of the supported platforms listed above

## Desktop App

Download the latest release from the [download page](/download), which serves
every build from a Cloudflare mirror, or from [GitHub Releases](https://github.com/YueMiyuki/risuko/releases):

- **macOS**: `.dmg` (Intel and Apple Silicon)
- **macOS (Homebrew)**: `brew install --cask yuemiyuki/risuko/risuko-app`
- **Linux**: `.AppImage`, or the [APT and DNF repositories](#linux-apt-and-dnf) on Debian, Ubuntu and Fedora
- **Windows** (x64 and x86): `.setup.exe` (NSIS installer, per-user) or `.portable.exe` (no install)
- **Android**: `.apk` (per-ABI builds)

Tagged desktop releases can include Tauri updater artifacts. The app checks the
Risuko update endpoint for the current target/architecture/version and verifies
the signed updater payload before installing it. Automatic update checks are
disabled by default on every platform; enable `auto-check-update` from
Preferences or `user.json` to opt in.

### Linux: APT and DNF

Debian and Ubuntu:

```bash
sudo curl -fsSLo /usr/share/keyrings/risuko.gpg https://dl.risuko.app/apt/risuko.gpg
echo "deb [signed-by=/usr/share/keyrings/risuko.gpg] https://dl.risuko.app/apt stable main" | sudo tee /etc/apt/sources.list.d/risuko.list
sudo apt update
sudo apt install risuko        # desktop app
sudo apt install risuko-cli    # CLI, runs as risuko-cli
```

Fedora and RHEL:

```bash
sudo curl -fsSLo /etc/yum.repos.d/risuko.repo https://dl.risuko.app/rpm/risuko.repo
sudo dnf install risuko        # desktop app
sudo dnf install risuko-cli    # CLI, runs as risuko-cli
```

These installs update through `apt` or `dnf`, so the in-app updater is turned off for them. Older versions stay in the repositories, so you can roll back with `sudo apt install risuko=<version>` or `sudo dnf downgrade risuko`.

### Linux: WebKitGTK rendering

On Linux, Risuko sets `WEBKIT_DISABLE_DMABUF_RENDERER=1` and
`WEBKIT_DISABLE_COMPOSITING_MODE=1` at startup when these variables are not
already defined in the environment. This works around a WebKitGTK 2.42+
crash on NVIDIA, virtualized GPUs, and Wayland sessions without a working
GBM backend (`Could not create GBM EGL display: EGL_NOT_INITIALIZED.
Aborting...` followed by SIGABRT before the window is shown). Export either
variable yourself before launching Risuko if you need to override the
default.

## Use App launcher

Install @risuko/app globally:
```package-install
npm install -g @risuko/app
```
Then run:
```bash
risuko-app
```

Each launch checks for the latest release. If it is not cached yet, the launcher downloads the desktop app for your platform from the Cloudflare mirror (falling back to GitHub Releases), verifies its release signature, and caches it per version; otherwise it launches the cached copy. When the check fails, for example offline, it launches the newest cached version. Use `--version <x.y.z>` to pin a specific release and `--no-cache` to force a re-download. Requires Node.js 22 or later.

## Building from Source

If you need to build Risuko yourself:

```bash
# Clone the repository
git clone https://github.com/YueMiyuki/risuko.git
cd risuko

# Install frontend dependencies
pnpm install

# Build the CLI only
cd src-tauri
cargo build --release -p risuko-cli
cd ..

# Build the full desktop app (adds the per-platform Tauri config)
pnpm build
```

### Build Requirements

- Rust 1.85+ (stable)
- Node.js 22+
- pnpm 11+
- Platform-specific dependencies (see [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/))
